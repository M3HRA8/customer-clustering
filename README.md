# Customer Clustering

A customer segmentation project using unsupervised machine learning techniques in Python.

## Overview

This project explores customer data and applies multiple clustering algorithms to identify groups of customers with similar characteristics.

## Methods

- K-Means Clustering
- DBSCAN
- Agglomerative Clustering
- StandardScaler for feature scaling
- LabelEncoder for encoding categorical data

## Evaluation and Visualization

- Elbow Method
- Silhouette Score
- K-Distance Graph
- Dendrograms
- 2D scatter plots

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- SciPy
- Google Colab / Jupyter Notebook

## Dataset

The notebook expects a dataset named `Cluster.csv`. The dataset is not included in this repository unless added separately.

## Notebook

The main analysis is available in `Cluster.ipynb`.

## Note

This project is intended for educational and machine learning practice purposes.
